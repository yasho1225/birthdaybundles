# Photo Assets

Drop real photos from the Drive export here, then copy to `public/images/photos/`:

| Filename | Used on |
|----------|---------|
| `hero.jpg` | Home hero |
| `mission.jpg` | Home mission section |
| `volunteer-packing.jpg` | Volunteer teaser, volunteer page |
| `volunteer-baking.jpg` | Volunteer teaser |
| `testimonial-1.jpg` … `testimonial-3.jpg` | Home testimonials |
| `team-1.jpg` … `team-3.jpg` | About page team |
| `gallery-1.jpg` … `gallery-6.jpg` | About gallery |

Recommended: JPEG or WebP, max 2000px wide, compressed for web.

Update paths in `src/config/images.ts` if filenames differ.
